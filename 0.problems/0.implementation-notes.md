# Implementation Notes

## Python Operators and Methods
1. `len()` is O(1) in python because it is stored as a property of the list object
2. the `in` dictionary operator is O(1) in most cases because python uses a hash computation with a key to locate its value. However if there's a hash collision (where different keys compute to the same hash value location), then python will need to do additional checks, which results in an O(n) complexity.
